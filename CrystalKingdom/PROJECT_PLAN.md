# Crystal Kingdom — 프로젝트 계획

환경 전용 프로젝트 (캐릭터·실내·게임 시스템 제외). 레퍼런스: 사용자가 제공한 수정 동굴 이미지
(`SourceArt/Reference/reference.webp`).

## 1. 개발 환경 (2026-11-09 점검)
| 항목 | 값 |

| Blender | 5.2.3 LTS (`C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`), Python 3.13 + numpy |
| GPU | NVIDIA GeForce RTX 2060, VRAM 6 GB |
| CPU / RAM | i7-10700 (16 threads) / 32 GB |
| Git / LFS | 2.45.2 / git-lfs 3.5.1 |
| Unreal MCP | 없음 → Python Remote Execution(`Tools/ue_remote.py`)으로 에디터 제어 |
| 디스크 | F: 여유 약 220 GB |

GPU가 RTX 2060 6GB이므로:
- Lumen은 **소프트웨어 트레이싱**(Mesh SDF) 기준. 하드웨어 RT는 끔 (2060에서 비용 과다).
- 텍스처 최대 2K, 반투명 굴절 수정은 근경 히어로 몇 개로 제한.
- 성능 목표는 측정 후 결정 (1440p 60FPS는 이 GPU에서 현실적이지 않을 가능성이 높음).

## 3. 공간 배치 (UE 좌표, m — X=북/카메라 전방, Y=동/오른쪽, Z=위)
동굴: X −60 … 440 (500 m), Y −175 … 175 (350 m), 천장 120–175 m, 호수 바닥 −18 m, 수면 Z=0.

| 구역 | 범위 | 내용 |
|---|---|---|
| Z1 남쪽 기슭 (전경) | X −60…30 | 카메라 위치 (0, 0, 9). 수정 블록 더미, 얕은 물, 수중 암석 |
| Z2 서쪽 수정 성채 | X 15…130, Y −175…−25 | 초대형 수정 기둥 군, 로지아 건물(X≈45, Y≈−42), 물가 대계단, 테라스 |
| Z3 중앙 호수·대교 | X 30…300, Y −70…70 | 호수, 대교(X≈175, Y −30…+45), 천장 채광구 3개 |
| Z4 동쪽 테라스 마을 | X 60…270, Y 40…175 | 계단식 암반 단구, 탑·홀·주택, 계단과 회랑, 수정 벽 |
| Z5 북쪽 심층 도시 | X 280…440 | 수정 단구 위 원경 탑·성당, 수정 벽, 안개 |

이동 동선 (향후 캐릭터용): 남쪽 기슭 → 서쪽 대계단 → 로지아 테라스 → 대교 서단 → 대교 → 동쪽 마을 광장 → 동쪽 계단 → 상부 회랑.
계단 단높이 18 cm / 단너비 32 cm, 통로·다리 폭 ≥ 4 m, 난간 1.1 m.

## 4. 제작 파이프라인
1. **Blender (헤드리스, Python)**: `SourceArt/Blender/*.py`가 절차적으로 메시를 만들어 `SourceArt/Export/**.fbx`와 `.blend`로 저장.
   - 텍스처: numpy FFT/Worley로 타일링되는 노멀·마스크 텍스처 생성.
   - 메시 정점 색: R = 조각별 난수, G = 결정 길이 방향 0→1, B = 면별 난수 (셰이더 변화용).
   - 건축물 충돌은 FBX `UCX_` 단순 박스/쐐기로 같이 내보냄.
2. **Unreal (Python Remote Execution)**: `Scripts/Unreal/*.py`가 FBX 임포트, Nanite, 머티리얼 생성, 레벨 배치, 조명, 카메라, 스크린샷까지 처리.
3. **검증**: 시네마틱 카메라에서 HighResShot 렌더 → 레퍼런스와 비교 → 수정 → 다시 렌더.
