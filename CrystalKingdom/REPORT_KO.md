## 2. 구현 내용
- **동굴**: 500 × 356 m, 천장 135–170 m. 노이즈로 변형한 초타원체 셸(능선·층리·천장 돌출 암괴)을 32청크로 나눴고, 채광구 굴뚝 3개를 뚫었습니다. 호수 분지 높이장 바닥은 12청크입니다 (가까운 쪽은 얕고 중앙은 −17 m).
- **수정**: 13유형 58메시. 불규칙 다각형 단면, 성장 줄무늬 링, 비대칭 능면 끝단과 끌 모양 끝단, 부러진 끝, 비틀림·테이퍼, 위성 결정이 들어갑니다. 레퍼런스의 수정 고층 덩어리는 기둥 군집(ColumnMass)으로 재현했고, 이를 거꾸로 매달아 천장 샹들리에 수정을 표현했습니다.
- **배치**: 랜드마크 18개는 수동으로 배치했습니다. 나머지는 레이트레이스로 천장(아래 방향)·벽(법선 방향)·물가(위 방향) 표면에 붙였고, 건물·다리·호수 중앙·카메라 시야 구역은 제외했습니다. 시드는 4242로 고정해 재현 가능합니다.
- **도시 외관**: 고딕 모듈 23종을 조합한 완성 건물 14종을 만들었습니다.
  - 2층 아치 로지아, 장미창이 있는 홀, 돔 종루 원탑, 첨탑과 총안이 있는 사각탑, 대성당(쌍탑·후진·첨탑), 주택 6종
  - 아치 4개 대교(정자 2, 등불), 분수 광장, 3단 대계단
  - 문은 닫힌 외관만 있고 실내는 없습니다.
- **호수**: Single Layer Water. 2층 잔물결이 흐르고, 산란·흡수 계수로 청록색을 내며, Lumen 반사로 창문빛과 수정이 비칩니다.
- **조명**:
  - 채광구 스포트 광선 5개(볼류메트릭 산란 9), 볼류메트릭 높이 안개(청록 산란)
  - 수정 보조광 7개, 천장 보조광 6개, 얕은 물 보조광 4개, 창문·계단·다리 웜라이트 21개, 저강도 SkyLight
  - 수동 노출 +2.2 EV, 블룸과 색보정
- **카메라 · 확인 기능**: 시네 카메라 6개(레퍼런스 구도, 동굴 전경, 거대 수정, 건축, 호수, 근접 디테일). 자유 비행 게임모드는 메시 없는 SpectatorPawn이며, PlayerStart를 레퍼런스 카메라 위치에 두었습니다.

## 3. 사용 기술
- **렌더링**: Lumen GI·반사(소프트웨어 SDF, 씬 뷰 거리 600 m), Nanite(불투명 메시 전부), Virtual Shadow Maps, 볼류메트릭 포그, TSR, Single Layer Water, Lumen 전면 반투명 반사
- **에셋 파이프라인**: Blender 헤드리스 Python(bmesh, numpy FFT·Worley 텍스처) → FBX(정점 색·UCX) → UE Interchange(Python, 파일 단위 임포트)
- **에디터 자동화**: Python Remote Execution(UDP 멀티캐스트 + TCP)으로 실행 중인 에디터에 스크립트를 보내 임포트·머티리얼 그래프·레벨 조립·렌더(HighResShot)를 수행
- **셰이더**: 커스텀 HLSL 노드 — 코사인 팔레트 박막 간섭, 프레넬 림 발광, BumpOffset 시차 내부 균열, 정점 색 기반 결정면 변화, 월드 좌표 물가 젖음
- **검증**: 단순 충돌 레이트레이스 프로브, CSV 프로파일러(`-csvGpuStats`)
- **PCG**: 플러그인만 활성화했고 그래프는 쓰지 않았습니다 (6절 참고)

## 6. 확인된 성능 (독립 실행, 레퍼런스 카메라 위치)
- 1080p TSR(엔진 기본 스케일): **60.1 fps**, GPU 15.6 ms
- 1080p 네이티브: **40.2 fps**, GPU 23.6 ms
- 내부 1440p: **25.7 fps**, GPU 37.6 ms

**1440p 60 FPS 목표는 미달성입니다.** RTX 2060 기준 현실적인 목표는 1080p + TSR 60 fps로 판단합니다. 자세한 내용은 `VALIDATION.md` 4절에 있습니다.

## 7. 해결하지 못한 문제 · 미완료 사항
1. 재질과 형태의 사실감이 레퍼런스에 미치지 못합니다 (5절).
2. PCG 그래프 · HISM으로 전환하지 않았습니다. 산포는 Python 레이트레이스이고 StaticMeshActor 약 900개입니다. Nanite로 렌더 비용은 감당되지만 에디터 액터 수가 많습니다.
3. Cinematic / Optimized 모드 프리셋을 분리하지 않았습니다.
4. 자유 비행 폰에 속도 조절·지정 카메라 복귀 입력이 없습니다. Python으로는 블루프린트 그래프를 만들 수 없어, 엔진 디버그 카메라(`ToggleDebugCamera`)와 `RestartLevel`로 대체했습니다.
5. 독립 실행 첫 프레임에 처리된 ensure 1회가 발생합니다 (행렬 정밀도 경고). 원인은 미확인이고 화면 영향은 없습니다.
6. Directional Light는 원거리 VSM 누수 때문에 강도 0으로 두었고, 광선은 스포트라이트로 대체했습니다.
7. 스크린샷은 에디터 뷰포트 HighResShot(1920×1080)이며, Movie Render Queue 렌더는 아닙니다.

## 8. 후속 캐릭터 · 실내 개발 준비
- 보행 표면 충돌 12/12 검증. 계단 18/32 cm, 다리 폭 8 m, 난간 1.1 m.
- 호수 수면은 충돌이 없으므로 물 경계는 별도 볼륨이 필요합니다.
- 닫힌 건물은 박스 충돌이라 실내를 만들 때 세부 충돌로 교체해야 합니다.
- 건축은 모듈형이라 생성기에서 문을 여는 버전(`portal`)과 실내 슬래브를 추가하기 쉽습니다.
- 모든 배치는 스크립트로 재현할 수 있습니다 (`ck_build_level.py`). 에셋을 수정한 뒤 다시 생성해도 레벨을 다시 맞출 수 있습니다.
- 세부 계획은 `NEXT_STEPS.md`에 있습니다.
